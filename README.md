### Current Project

**[TEMMS](https://github.com/LewisJor/temms)** - Tactical Edge Model Management System

TEMMS is an offline-first model management daemon for edge hardware. It switches ML models based on local conditions like visibility, battery, temperature, operator overrides, or mission phase, without assuming the device can reach the cloud.

The project includes a policy engine, model slots, condition collection, FastAPI inference endpoints, Docker-based simulation, MLflow integration, and a visual weather simulation for testing model switching behavior.
